## What I'm building

### [Proxylang](https://proxylang.dev)

<a href="https://proxylang.dev/?utm_source=github&utm_medium=profile">
  <img src="https://raw.githubusercontent.com/Proxylang/handoff-bar/main/site/proxylang-banner.png" width="640" alt="Proxylang translates websites into 77 languages with one line of code">
</a>

Proxylang translates your whole website into 77 languages with one line of code. It translates text inside images too. No rebuild and no translation files to manage.

### [HandoffBar](https://handoffbar.proxylang.dev)

<a href="https://handoffbar.proxylang.dev">
  <img src="https://raw.githubusercontent.com/Proxylang/handoff-bar/main/site/icon.png" width="64" align="left" alt="HandoffBar icon">
</a>

A free menu bar app for Mac and Windows. Claude Code chats get expensive once their cache expires, because the next message re-reads the whole chat at full price. HandoffBar saves a short handoff of each chat so you can pick it up in a fresh one without burning tokens.

[Download for Mac](https://github.com/Proxylang/handoff-bar/releases/latest/download/HandoffBar.dmg) · [Get it on the Microsoft Store](https://apps.microsoft.com/detail/9nsk9p03t9cn) · [Source](https://github.com/Proxylang/handoff-bar)
